# FND-01: Frontend Setup

**Status:** Completed

## Objective

Initialize React + Vite + TypeScript in `frontend/`.

## Scope

- Set up React, Vite, and TypeScript.
- Install Ant Design.
- Configure ESLint.
- Add development and build scripts.

## Acceptance Criteria

- `npm run dev` starts the frontend locally.
- The default React page loads without errors.
- `npm run build` succeeds.
- `npm run lint` passes.

## Out of Scope

- Routing and layouts.
- Authentication.
- Testing infrastructure.
