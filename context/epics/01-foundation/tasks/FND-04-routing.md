# FND-04: React Routing

**Status:** Not Started

## Objective

Set up client-side routing using React Router in `frontend/`.

## Scope

- Install and configure React Router.
- Create placeholder pages for Login, Register, Dashboard, My Cases, Case Details, Submit Case, and Profile.
- Configure routes for each page.
- Add a Not Found (404) page.

## Acceptance Criteria

- Each route displays its corresponding page.
- Navigation works without full-page reloads.
- Direct URL access and browser refresh work.
- Unknown routes display the Not Found page.

## Out of Scope

- Page layouts and styling.
- Authentication and protected routes.
- Business functionality.
