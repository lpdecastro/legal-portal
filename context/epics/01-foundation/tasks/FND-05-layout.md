# FND-05: React Layout

**Status:** Not Started

## Objective

Set up shared public and authenticated layouts using Ant Design in `frontend/`.

## Scope

- Create public layout for Login and Register pages.
- Create authenticated layout with sidebar, header, and main content area.
- Add navigation links to existing routes.
- Implement responsive layouts for desktop and mobile.
- Apply consistent typography, colors, and spacing.

## Acceptance Criteria

- Login and Register pages use the public layout.
- Dashboard, My Cases, Case Details, Submit Case, and Profile pages use the authenticated layout.
- Sidebar navigation works across pages.
- Layouts adapt to desktop and mobile screens.
- Active navigation item is highlighted.

## Out of Scope

- Authentication and protected routes.
- Actual page content and business functionality.
- API integration.
