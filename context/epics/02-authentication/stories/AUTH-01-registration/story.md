# AUTH-01: Client Registration

**Status:** Not Started

## User Story

As a client, I want to register an account so I can access the platform.

## Acceptance Criteria

- Clients can register using their name, email, and password.
- Required fields are validated.
- Duplicate email addresses are rejected.
- Passwords are securely hashed before storage.
- Successful registration creates a client account and profile.
- Validation and registration errors are displayed clearly.

## Tasks

- AUTH-01-01: Registration API (BE)
- AUTH-01-02: Registration Form (FE)

## Definition of Done

- Both tasks are completed.
- Client registration works end-to-end.
- Automated tests pass.
