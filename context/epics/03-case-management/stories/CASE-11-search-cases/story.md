# CM-04: Search Cases

## User Story

As a client, I want to search my cases by title so I can quickly find a specific case.

## Page

My Cases (`/cases`)

## Acceptance Criteria

- Search cases by title.
- Support partial, case-insensitive matching.
- Show only matching cases belonging to the client.
- Update results when the search query changes.
- Show an empty state when no cases match.
- Clearing the search restores all cases.
- Reset pagination to the first page when searching.
