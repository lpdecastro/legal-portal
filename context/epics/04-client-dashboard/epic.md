# Epic: Client Dashboard

## Goal

Allow clients to view case statistics and recent cases from their dashboard.

## Stories

- DASH-01: View Case Statistics
- DASH-02: View Recent Cases

## Scope

- Display total, draft, submitted, and closed case counts.
- Display recent cases with links to case details.
- Use a single dashboard summary API.
- Show loading, empty, and error states.

## Done When

- Clients can view statistics and recent cases for their own cases only.
