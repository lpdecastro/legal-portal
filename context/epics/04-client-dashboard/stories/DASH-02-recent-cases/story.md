# DASH-02: View Recent Cases

## User Story

As a client, I want to see my recent cases so I can quickly access their details.

## Acceptance Criteria

- Display the 5 most recent cases, newest first.
- Show case title, status, and creation date.
- Allow clients to click a case to view its details.
- Display an empty state when no cases exist.
- Show loading and error states.
