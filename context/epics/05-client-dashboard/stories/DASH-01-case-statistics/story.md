# DASH-01: View Case Statistics

## User Story

As a client, I want to see my case statistics so I can quickly understand the status of my cases.

## Acceptance Criteria

- Display total, draft, submitted, and closed case counts.
- Count only cases belonging to the logged-in client.
- Display zero for statuses with no cases.
- Show loading and error states.
