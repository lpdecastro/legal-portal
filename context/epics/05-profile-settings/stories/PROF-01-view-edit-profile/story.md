# PROF-01: View and Edit Profile

## User Story

As a client, I want to view and update my personal information so that my profile stays accurate.

## Acceptance Criteria

- Client can view their first name, last name, email, and phone number.
- Client can update their first name, last name, and phone number.
- Email is read-only.
- Invalid inputs show validation errors.
- Profile changes persist after refreshing the page.
- Only authenticated clients can access their profile.

## Tasks

- **PROF-01-01:** Get Client Profile API
- **PROF-01-02:** Update Client Profile API
- **PROF-01-03:** View and Edit Profile UI
