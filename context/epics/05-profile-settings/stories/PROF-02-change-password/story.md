# PROF-02: Change Password

## User Story

As a client, I want to change my password to keep my account secure.

## Acceptance Criteria

- Client must provide their current password.
- Client must enter and confirm a new password.
- Current password must be correct.
- New password must meet password requirements.
- New password must differ from the current password.
- Invalid inputs show appropriate errors.
- Client can log in using the new password after a successful change.
- Only authenticated clients can change their password.
