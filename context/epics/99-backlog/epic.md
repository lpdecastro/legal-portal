# Epic: Backlog

**Epic ID:** BKL  
**Status:** Not Started

## Objective

Collect improvements and technical debt that are worth doing but aren't scheduled in any delivery epic. Items move into a delivery epic, or get picked up directly with `/feature load`, when they become a priority.

## Scope

- Technical improvements that don't change MVP behavior.
- Follow-ups noticed during feature work that are out of scope for that feature.

## Tasks

| ID     | Task                       | Status      |
| ------ | -------------------------- | ----------- |

## Out of Scope

- New MVP features. Those belong in their delivery epic.

## Definition of Done

- Each backlog item is either completed or moved into a delivery epic.
